Post文章中代码块无法被完整渲染的解决办法

Created on January 20, 2026

2026   ·   Jekyll

利用 <figure> 和 <pre> 或者 raw 和 highlight 元素包裹代码块

1. <pre> 元素：内容保全的基石


<pre> 是“预格式化文本”（Preformatted Text）的缩写，其核心设计原理是“所见即所得”。浏览器渲染 <pre> 标签内的文本时，会严格保留所有的空白字符（空格、制表符、换行符）。这与处理普通段落（<p>）的逻辑截然不同——普通段落中，连续的空白符会被合并成一个空格。
默认情况下，浏览器会为 <pre> 元素应用 white-space: pre; 这个CSS属性。这个属性值正是“保留所有空白，仅在换行符处换行”的指令。当你将代码直接放在 <pre> 标签内时，你实际上是在告诉Jekyll：“这部分内容我已经用原生HTML标记好了，不需要你进行Markdown到HTML的转换，更不需要调用语法高亮引擎（如Rouge）。” 这从根本上避免了因高亮引擎不支持某些语言而导致的渲染失败。

代码中的缩进、对齐、空行等结构会被原封不动地展示出来，这对于展示代码、命令行输出、ASCII图表等至关重要。

简单来说，<pre> 确保了内容的“形”不被改变。


2. <figure> 元素：语义关联的容器


<figure> 是一个语义化容器元素，其核心设计原理是“标记一个独立的内容单元，并允许为其提供说明”。它用来包裹一块独立、自包含的内容（如图片、代码、图表、引文），并通过可选的 <figcaption> 子元素，将内容与其标题/说明在语义上明确地关联起来。
从功能上讲，<figure> 本身就像一个 <div>，但赋予了更强的语义。浏览器或辅助技术（如屏幕阅读器）可以识别这种关联，从而更好地理解页面结构。它将 <pre>（代码块）和 <figcaption>（说明文字）捆绑成一个逻辑整体。这在文档结构上清晰地表明“这段代码和下面的标题是一体的”。
这种语义化的标记有助于屏幕阅读器用户理解内容关系，同时向搜索引擎清晰地传达了内容的结构。它为你提供了一个完美的、语义正确的“包装盒”，让你可以方便地为整个代码块单元（包括代码和说明）应用统一的CSS样式，比如添加边框、背景或外边距，而无需使用无语义的 <div>。
简单来说，<figure> 确保了内容与说明的“关系”被清晰地定义。


3.避免 html或者liquid代码块被执行的解决办法

使用capture 变量 + raw 包代码 + xml_escape输出纯文本的样式，保留缩进、空行，可随手加语法高亮，多段代码互不串扰。

原始代码 Click here to know more 
  
    

{% capture code %}
    {%raw1%} #真正执行时需要改为`raw`，并且前后需要加空格
        <div class="example">
            {{ page.title }}
            {% if page.comments %}
                <p>Comments enabled</p>
            {% endif %}
        </div>
    {%endraw1%}
{% endcapture %}
<pre class="keep-indent">
  <code class="language-html">
    {{ code | xml_escape }}
  </code>
</pre>
实际效果 Click here to know more 
  
    
 
<div class="example">
  {{ page.title }}
  {% if page.comments %}
      <p>Comments enabled</p>
  {% endif %}
</div>

NOTE: 需要添加keep-indent的样式设置

层级关系： pre.code code { … } /* 匹配 <pre class="code"> 里的 <code> */

% raw % 和 % endraw % 是 Liquid 模板语言自身的“逃逸”指令。
当 Jekyll 处理你的 .md 或 .liquid 文件时，它会执行文件中的 Liquid 代码。但遇到 % raw %% endraw % 时，它会将这对标签及其包裹的所有内容视为纯文本，不进行任何 Liquid 解析或变量替换。

4. highlight 命令

Jekyll 内置了 Rouge，用 highlight language linenos 即可，它自动套用格式 <pre><code class="language-××">，大部分语言的代码块都可以用这样的方式操作。

  
    

{% highlight yaml linenos %}
giscus_comments: true  # 启用 Giscus 评论系统
disqus_comments: true  # 启用 Disqus 评论
{% endhighlight %}
