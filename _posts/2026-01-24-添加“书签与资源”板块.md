# al-folio 模板中添加“书签与资源”板块的完整实现指南

在 al-folio 学术网站模板中添加一个功能完整、美观实用的**书签与资源（Bookmarks）**页面，是一个非常典型的自定义扩展案例。下面详细记录整个实现过程、核心逻辑、代码原理和关键技巧，供后续维护、复用或学习参考。

## 1. 设计目标与最终效果

- 集中管理大量外部链接资源（60+ 条）
- 支持按分类组织
- 每个书签显示：标题、描述、域名、网站 favicon
- 页面内容接近全宽显示
- 每个分类可折叠/展开
- 顶部实时搜索（支持标题、描述、域名模糊匹配）
- 交互优雅：悬停高亮、图标动画、深色模式完美支持
- 维护成本极低：所有数据集中在一个 YAML 文件

## 2. 核心实现思路（为什么选择这种方式）

al-folio 提供了多种展示集合的方式：
- Collection（每个条目一个 md 文件）→ 适合少量项目（如 Projects、Recipes）
- `_data/*.yml` + Liquid 循环 → 适合大量条目、频繁更新

由于书签数量多、经常增删，最终选择 **`_data/bookmarks.yml` + 单页面渲染** 的方案：
- 所有数据集中管理，修改只需编辑一个文件
- 无需自定义 layout，避免 Liquid 继承错误（如 `extends` 不支持）
- 完全利用 Bootstrap 5 原生组件（list-group、collapse、form-control）
- 通过少量 CSS + JS 实现高级交互

<script>
  document.getElementById('bookmarkSearch').addEventListener('input', function(e) {
    const query = e.target.value.toLowerCase().trim();
    document.querySelectorAll('.bookmark-item').forEach(item => {
      const title = item.dataset.title;
      const desc = item.dataset.desc;
      const domain = item.dataset.domain;
      const matched = title.includes(query) || desc.includes(query) || domain.includes(query);
      item.style.display = matched ? '' : 'none';
    });

    // 可选：搜索时自动展开有结果的分类
    document.querySelectorAll('.collapse').forEach(collapse => {
      const hasVisible = collapse.querySelector('.bookmark-item[style=""]');
      if (hasVisible) {
        bootstrap.Collapse.getInstance(collapse)?.show();
      } else {
        bootstrap.Collapse.getInstance(collapse)?.hide();
      }
    });
  });
</script>

## 6. 关键技术点总结

| 功能           | 实现方式                                      | 原理说明 |
|----------------|-----------------------------------------------|----------|
| 数据管理       | `_data/bookmarks.yml`                         | Jekyll 自动加载为 `site.data`，集中维护 |
| 全宽布局       | `container-fluid` + `col-xl-11`               | 突破默认 930px 限制，接近全屏 |
| 纵向列表       | Bootstrap `list-group` + flex                 | 每条占一行，信息完整显示 |
| Favicon 显示   | Google Favicon API                            | `https://www.google.com/s2/favicons?domain=URL` |
| 可折叠分类     | Bootstrap 5 `collapse` + JS 事件              | 原生支持，无需额外库 |
| 实时搜索       | 原生 JS `input` 事件 + `dataset` 属性          | 模糊匹配标题/描述/域名，隐藏不匹配项 |
| 交互美化       | CSS 变量 + transition                         | 完全适配深色模式 |

## 7. 优点与可扩展性

- **维护成本极低**：增删书签只需修改一个 YAML 文件
- **零外部依赖**：全部使用 Bootstrap 5 + 原生 JS
- **高度兼容**：不依赖任何未启用插件，完全适配 al-folio
- **可扩展方向**：
  - 添加标签（tags）多条件筛选
  - 侧边栏固定分类目录
  - 一键复制链接按钮
  - 导出为 JSON/OPML

这个实现方案在简单性、美观性和功能性之间达到了极佳平衡，已成为个人网站中最实用的模块之一。
